# Number Guessing Game

A simple Number Guessing Game built with HTML, CSS, and JavaScript.

## About

This is a simple number guessing game where the player tries to guess a randomly generated number.

The game gives feedback based on the player's guess and updates the webpage dynamically using JavaScript DOM manipulation.

## Features

• Generates a random number
• Takes user input
• Checks the guessed number
• Shows whether the guess is too high, too low, or correct
• Tracks the number of attempts
• Allows the player to play again

## Technologies Used

• HTML5
• CSS3
• JavaScript
• DOM Manipulation

## How to Play

1. Enter a number in the input field.
2. Click the Guess button.
3. Check the feedback.
4. Continue guessing until you find the correct number.
5. Try to guess the number using as few attempts as possible.

## Learning Goal

The main goal of this project is to practice JavaScript DOM manipulation, event handling, user input, and basic game logic.
